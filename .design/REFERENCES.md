# 参考来源

## 视觉/案例参考

1. [Awwwards Music & Sound 合集](https://www.awwwards.com/websites/music-sound)
   - 类型：网站案例合集
   - 可复用点：音乐类网站如何把曲目/演出/联系做信息分层；深色背景下的高对比信息层级
   - 不复制：具体配色、字体、动效

2. [Awwwards Retro Websites 合集](https://www.awwwards.com/websites/retro)
   - 类型：网站案例合集
   - 可复用点：复古未来感的视觉处理（像素/扫描线/CRT/磁带元素）；非对称布局打破模板感
   - 不复制：任何具体案例的视觉风格

## GitHub 代码/结构参考

3. [aryanjohnsharma/aryanjohnsharma.github.io](https://github.com/aryanjohnsharma/aryanjohnsharma.github.io)
   - 类型：React + Vite 个人作品集
   - 技术栈：Vite, React, Framer Motion, React Router, Lucide, OGL
   - 可复用结构：
     - 单页应用 + 锚点滚动导航
     - 意图驱动的动画（intentional motion）
     - 深色主题下的干净 UI
   - 不复制：开发者作品集的内容组织；具体组件样式

4. [arnobt78/Portfolio-Landing-Page-15--React-Frontend](https://github.com/arnobt78/Portfolio-Landing-Page-15--React-Frontend)
   - 类型：React + Vite 单页作品集模板
   - 技术栈：React, Vite, Tailwind CSS, Framer Motion
   - 可复用结构：
     - `src/data/constants.js` 集中管理内容
     - `src/components/` 按 section 拆分（navbar, hero, projects, education, contact, footer）
     - Framer Motion 做 section entrance、hover、modal 动画
     - 平滑滚动到锚点
   - 不复制：模板默认的浅色/紫色视觉；教育经历等开发者专属模块

5. [Gothsec/dark-minimal](https://github.com/Gothsec/dark-minimal)
   - 类型：Astro + React 深色作品集
   - 技术栈：Astro, React, TypeScript, TailwindCSS
   - 可复用结构：
     - Hero + Projects + About + Contact 的单页信息组织
     - 深色模式默认
   - 不复制：极简灰度视觉；字体选择

6. [Sahilmd01/React-Portfolio](https://github.com/Sahilmd01/React-Portfolio)
   - 类型：React + Vite 作品集
   - 技术栈：React, Vite, Tailwind CSS
   - 可复用结构：
     - 快速构建、响应式
     - 适合作为静态站点输出
   - 不复制：开发者导向的内容和布局
